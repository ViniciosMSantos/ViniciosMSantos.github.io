analises_olist — Análise exploratória do dataset Olist

Python pandas Jupyter Notebook Power BI
Ver no GitHub ↗

Contexto

Análise exploratória e tratamento do dataset público Olist Brazilian E-commerce (Kaggle), com saída para um dashboard em Power BI.

O que foi feito

As 9 tabelas originais (clientes, geolocalização, pedidos, itens de pedido, pagamentos, avaliações, produtos, vendedores, tradução de categorias) foram carregadas, exploradas por volume e valores nulos, e tratadas:

  • 610 produtos sem categoria (product_category_name) — preenchidos com "Sem Informação"
  • 160 pedidos sem data de aprovação de pagamento (~0,2% do total) — mapeados, mas mantidos como ausência real, não preenchidos
  • Nulos em datas de entrega ao transportador (1.783) e ao cliente (2.965) — referentes a pedidos ainda não despachados/entregues
  • Título e comentário de avaliação ausentes em boa parte dos registros — tratado como esperado, já que são campos opcionais para o cliente

Os dados tratados foram exportados para CSV, servindo de fonte para o dashboard Power BI (dash.pbix).

Tecnologias

Python · pandas · Jupyter Notebook · Power BI

Resultado

Base de dados tratada e documentada, pronta para consumo analítico, com um dashboard em Power BI construído em cima dela.
