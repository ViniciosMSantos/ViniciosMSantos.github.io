portal_bi — Portal de Dashboards

Python Flask PostgreSQL / Lakebase Databricks Apps JavaScript
Ver no GitHub ↗

Contexto

Portal corporativo para centralizar e controlar o acesso a dashboards, links e ferramentas internas, no lugar de terem links espalhados. Roda como Databricks App, com backend Flask e banco Lakebase (PostgreSQL gerenciado pelo Databricks).

Funcionalidades

  • Navegação SPA por pastas e subpastas, sem reload de página
  • Busca em tempo real na sidebar, filtrando por nome/descrição
  • Chat de IA integrado ao Databricks Genie — perguntas em linguagem natural sobre os dados dos dashboards, com memória de conversa entre perguntas
  • Fluxo de solicitação e aprovação de acesso para usuários novos
  • Painel administrativo (roles ADMIN/MANAGER): aprovar acessos, ativar/desativar usuários, controlar quem tem acesso à IA
  • Controle de acesso por role (USER / BA / MANAGER / ADMIN), por tag e por concessão individual

Arquitetura

Flask (factory pattern + Blueprints) → Databricks Lakebase (PostgreSQL, via OAuth2 client_credentials) · Databricks Genie Conversation API para o chat de IA

Autenticação do usuário via header X-Forwarded-Email do próprio Databricks Apps. Deploy como Databricks App, rodando com gunicorn.

Tecnologias

Python 3.11 · Flask · PostgreSQL (Databricks Lakebase) · JavaScript vanilla + Jinja2 · Databricks Genie API · Databricks Apps (deploy)
